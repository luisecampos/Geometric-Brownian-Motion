# assets/

Drop a logo image here named `logo.png`, `logo.jpg`, or `logo.jpeg` and the
corner badge in the game will pick it up automatically on next launch — see
`ui.load_logo()` / `ui._draw_badge()`.

No file here yet -> badge falls back to a small drawn blue "P" monogram.

Note: logo image files themselves are git-ignored (see the root
`.gitignore`), since a real company's logo isn't something to keep in
version control. This README is the only thing meant to be tracked here.
